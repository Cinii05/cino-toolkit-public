Support

For installation or behaviour problems with Cino Toolkit, first record:

  • the ChatGPT or Codex surface you are using;
  • the plugin version;
  • the skill you expected to run;
  • the prompt that reproduced the issue; and
  • the exact error or unexpected behaviour.

Support requests are handled through the Cino Toolkit GitHub issue tracker.

Cino Toolkit does not provide emergency, regulated-professional, account-billing, or OpenAI platform support. OpenAI product/account issues should be directed to OpenAI's own support channels.
