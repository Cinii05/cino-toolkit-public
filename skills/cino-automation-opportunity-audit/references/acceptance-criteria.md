# Acceptance criteria — cino-automation-opportunity-audit

- AC-01 — Frontmatter name is exactly cino-automation-opportunity-audit.
- AC-02 — Description positively routes real business workflow/automation-opportunity diagnosis.
- AC-03 — Description excludes generic proposal critique, open-ended interview mode, UX audit, and implementation/deployment.
- AC-04 — Routing precedence is explicit for all seven pre-existing Toolkit skills.
- AC-05 — Pre-install deterministic routing-contract fixtures resolve to the expected owner/sequence; this is not treated as proof of the live ChatGPT router.
- AC-06 — Evidence labels are CLIENT_FACT, SOURCE_FACT, DIRECT_INFERENCE, ASSUMPTION, and UNKNOWN.
- AC-07 — Unknown labour/volume/cost data cannot silently become an ROI claim.
- AC-08 — Savings/revenue are never guaranteed and scenario assumptions remain labelled.
- AC-09 — Existing product capabilities are checked before custom-build recommendations.
- AC-10 — The audit can recommend existing configuration, process change, human work, evidence gathering, or no automation.
- AC-11 — Clear bounded repetitive work can reach CONTINUE with AUTOMATE_CANDIDATE.
- AC-12 — High-impact actions can only reach a first pilot with a human approval gate or a more conservative decision.
- AC-13 — Low-value/low-frequency work can be rejected when custom automation is unjustified.
- AC-14 — Insufficient decision-critical evidence results in PAUSE / NEEDS_EVIDENCE.
- AC-15 — Every recommended pilot specifies trigger, steps, human gate where required, outputs, failure alert, fallback, logging, acceptance measures, rollback, and trial scope.
- AC-16 — Report contract includes decision, workflow, bottlenecks, classifications, economics, risks, ranked opportunities, smallest intervention, measurements/rollback, and next safe action.
- AC-17 — Original seven R2 skill source files remain byte-for-byte equal to the verified parent baseline.
- AC-18 — No path created by this Skill #8 build contains or modifies Foundation R1.
- AC-19 — All deterministic audit and economics fixtures produce expected decisions, classifications, calculations, and unknown handling.
- AC-20 — All deterministic routing fixtures produce the expected Toolkit skill or explicit sequential skill chain.

- AC-21 — After installing the candidate in a test/development slot, real ChatGPT discovery/activation checks reproduce the critical ambiguous routing outcomes, including Skill #8 vs Critical Review and the Video Intelligence -> Automation Opportunity Audit sequence.

A candidate package should not be created while any AC-01 through AC-20 is red. AC-21 is a post-install promotion gate: the candidate may be packaged with AC-21 pending, but it must not be promoted/published as the live R2 release until AC-21 passes.
