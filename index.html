Focused workflows for better AI-assisted work

Cino Toolkit is a skills-only plugin for ChatGPT and Codex. It packages seven reusable workflows for critical review, product-design audits, video analysis, guided planning, programming tuition, The Moving Chain frontend work, and natural-language editing.

Included skills

  • Cino Critical Review — stress-tests plans, claims, specifications, and implementation proposals.
  • Cino Product Design Review — performs evidence-backed UI and UX audits.
  • Cino Video Intelligence — separates what accessible footage demonstrates from what a creator merely claims.
  • Grill Me — interrogates a plan one consequential decision at a time.
  • Teach Programming Step by Step — teaches coding using plain language, examples, checks, and quizzes.
  • TMC UI Master — audits, plans, implements and verifies authorised frontend UI and UX work for The Moving Chain while protecting business-critical invariants.
  • Unslop — rewrites requested prose to reduce generic AI-writing patterns while preserving meaning.

Data and accounts

Cino Toolkit is skills-only. It does not operate its own backend, require a Cino Toolkit account, or independently collect user data.

Published by Max Cini. Cino Toolkit is an independent plugin and is not an OpenAI product.
