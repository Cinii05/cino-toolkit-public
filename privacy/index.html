Privacy policy

Effective date: 17 September 2026

Publisher: Max Cini

What Cino Toolkit is

Cino Toolkit is a skills-only plugin. It provides reusable instructions for analysis, product-design review, video analysis, guided planning, programming tuition, and writing assistance.

Personal data collected by the plugin publisher

Cino Toolkit does not operate a publisher-controlled backend, user account system, analytics service, advertising system, payment system, or contact form. Max Cini does not independently receive or store the text, files, images, video, links, or other content that users provide to ChatGPT or Codex merely because they use Cino Toolkit.

The only publisher-facing support channel is the public Cino Toolkit GitHub issue tracker. If a user voluntarily opens or comments on a GitHub issue, the information visible to the publisher can include the user's GitHub username, issue or comment text, and any attachments or other information the user chooses to post.

Purposes of use

Information voluntarily submitted through the GitHub issue tracker is used only to respond to support requests, reproduce reported problems, maintain the plugin, and improve its documented behaviour.

Recipients

Support information posted to the public GitHub issue tracker is processed by GitHub under GitHub's own terms and privacy policy and may be visible publicly because the repository is public. Max Cini does not sell this information or disclose it to advertisers.

Text, files, images, video, links, and other material that a user provides directly in ChatGPT or Codex are handled by OpenAI under the terms, privacy settings, and product controls that apply to that user's OpenAI account. If the user separately chooses to use a connected third-party app or service, that provider's own terms and privacy policy may also apply.

Retention

Cino Toolkit itself retains no user conversation content because it has no publisher-operated backend. Support information posted to GitHub may remain in the public repository's issue history until it is edited, deleted, or otherwise removed through GitHub or repository moderation. GitHub may retain data independently in accordance with its own policies.

User controls

Users can avoid submitting personal or sensitive information in public support issues. Where GitHub provides the relevant controls, users can edit or delete their own issue comments. Users may also request removal of support content through the Cino Toolkit GitHub issue tracker. Users can uninstall or stop using Cino Toolkit through the controls available in their OpenAI product.

Permissions and external actions

Cino Toolkit does not grant itself new permissions and does not bypass existing access controls. The public skills are designed to disclose evidence gaps and not to perform consequential external writes without user authorisation and an available permitted capability.

Sensitive information

Users should not post passwords, API keys, authentication codes, payment-card information, government identifiers, health information, or other sensitive information in public GitHub issues. More generally, users should avoid providing personal information that is not necessary for the task.

Changes

This policy may be updated if the plugin's data handling or technical architecture changes. The effective date on this page will be updated when a material change is published.

Contact

Support and privacy enquiries can be raised through the Cino Toolkit GitHub issue tracker.

Published by Max Cini. Cino Toolkit is an independent plugin and is not an OpenAI product.
