# Cino skills-only plugins privacy policy

Effective: 5 October 2026

This policy covers the skills-only Cino Academy and Cino StarNet plugins published by Max Cini.

## Data processed

The plugins are instruction packages that run inside ChatGPT/Codex. They do not operate a publisher-owned MCP server, analytics service, database, or telemetry endpoint. The publisher does not independently receive or store the conversation text, files, repository content, academic material, or other information a user provides to ChatGPT/Codex merely because one of these skills is installed or activated.

The skills may instruct ChatGPT/Codex to inspect information the user supplies or legitimately connects when needed for the user's request. Data handling by ChatGPT/Codex and any separately connected service is governed by the applicable provider terms and privacy controls.

## Purpose and minimization

The skills direct the assistant to use only information needed for the requested workflow. Cino Academy uses supplied academic material for evidence-grounded academic support. Cino StarNet uses task, repository, verification, and agent context for routing and reliability workflows. Neither plugin should request credentials, payment-card data, government identifiers, or other restricted data as part of ordinary operation.

## Recipients and sharing

The plugin publisher does not receive plugin-use data through a publisher-controlled service. If a user separately directs ChatGPT/Codex to use a connected third-party service, information may be sent to that service under its own permissions and policies.

## Retention

The publisher retains no user conversation or file data through these skills-only plugins. Retention by ChatGPT/Codex or separately connected services is controlled by those services and the user's settings.

## User controls

Users can choose what information to provide, decline or disconnect external services, remove a plugin, and use the privacy/data controls offered by ChatGPT/Codex and any connected service.

## Contact

For questions or privacy concerns, open a support issue at https://github.com/Cinii05/cino-toolkit-public/issues and identify the affected Cino plugin.
