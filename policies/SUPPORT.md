# Cino plugin support

Support for Cino Toolkit, Cino Academy, and Cino StarNet is handled through the public issue tracker:

https://github.com/Cinii05/cino-toolkit-public/issues

Include the plugin name, version, the expected behavior, what happened, and any non-sensitive reproduction steps. Do not post credentials, private academic work, client data, API keys, or other secrets in a public issue.
